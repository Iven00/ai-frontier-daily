1. 經營者與聯絡方式

  • 經營者：陳宜寬（個人經營）。
  • 聯絡 email：rooteric@gmail.com。查詢、更正、刪除個人資料或對本政策有疑問，都請寄到這個信箱。

2. 服務說明

  • 「AI 前沿情報日刊」提供每日 AI 情報網頁、雙主持 Podcast 語音，以及電子報（email）。
  • 瀏覽網頁與收聽語音不需要登入。訂閱電子報時，使用 Google 帳號登入（Sign in with Google）。
  • 訂閱、電子報與閱讀行為紀錄等功能正在建置中；本政策說明這些功能上線後的運作方式。功能上線前，本站不蒐集下列第 3、4 節的資料。

3. 透過 Google 登入取得的資料

  • 只要求 Google 的基本範圍：openid、email、profile。
  • 取得的資料只有：你的姓名、email 地址、大頭貼照片，以及 Google 帳號的識別碼（用來辨認同一位訂閱者）。
  • 我們不會存取你的 Gmail 信件、雲端硬碟、聯絡人、行事曆或任何其他 Google 資料。
  • 本服務使用與傳輸從 Google API 取得的資訊時，會遵守 Google API 服務使用者資料政策（Google API Services User Data Policy），包括其中的有限使用（Limited Use）規定。

4. 在網站上蒐集的資料

  • 匿名訪客代碼：第一次造訪時，瀏覽器會產生一組隨機編號，存在你的瀏覽器裡。這組編號本身不包含姓名或 email。
  • 閱讀行為：看過哪些頁面與分類、捲動深度、語音收聽進度、點擊、從哪個網站連過來（referrer），以及造訪時間。
  • 電子報連結：寄給訂閱者的信中，連結會帶一組個人代碼（token），讓我們知道你點了哪些連結、是否仍在閱讀。
  • 我們不使用開信追蹤像素（不追蹤你是否打開信件）。

5. 蒐集與利用目的

  • 提供服務：管理訂閱、寄送電子報與通知信。
  • 了解哪些內容對讀者有用，並據此改善內容與網站，讓網站更容易被找到。
  • 分析讀者興趣，包括辨識經營者所開發之相關產品或服務的潛在使用者或合作對象。
  • 聯繫方式的限制：除了訂閱的電子報與相關通知信之外，經營者不會主動以其他方式聯繫你；只有在你回覆來信，或另外明確表示同意時，才會進一步聯繫。

6. 儲存位置與分享對象

  • 資料存放在經營者私人的 Google 帳號中（Google 試算表 Google Sheets 與 Google Apps Script）。
  • 資料不公開、不出售，也不會分享給第三方；唯一例外是作為服務提供者的 Google（登入、資料儲存與寄信）。
  • 網站本身架設在 GitHub Pages；GitHub 作為網站主機，可能依其政策記錄連線資訊（例如 IP 位址），這部分不經過我們，也不會與上述資料合併。

7. 保存期間與刪除

  • 資料會保存到經營者刪除為止。取消訂閱後，你的資料仍會保留。
  • 你可以隨時寄信到 rooteric@gmail.com 要求刪除，經營者會刪除你的個人資料。

8. 不活躍提醒與自動取消訂閱

  • 「活躍」只看兩件事：點電子報中帶個人代碼的連結，或用已綁定的瀏覽器造訪網站。
  • 連續 X 天（預設 10 天）沒有活躍紀錄時，會寄一封提醒信，你可以選擇繼續訂閱。
  • 連續 N 天（預設 13 天）沒有活躍紀錄時，訂閱會自動取消並寄出通知。之後隨時可以重新訂閱。

9. 取消訂閱

  • 每封電子報都有取消訂閱按鈕，按一下即可取消，不需要登入。

10. 追蹤的選擇：歐盟訪客、〔不要追蹤〕、DNT 與 GPC

  • 歐盟／歐洲經濟區（EU/EEA）的訪客：取得你的同意之後才開始追蹤；未同意前不產生訪客代碼、不記錄閱讀行為。
  • 其他訪客：網頁上會有明顯的〔不要追蹤〕選項，按下後即停止記錄閱讀行為。
  • 瀏覽器送出「不要追蹤」（Do Not Track，DNT）或「全球隱私控制」（Global Privacy Control，GPC）訊號時，一律不追蹤。
  • 以上為相關功能上線後的運作方式。

11. Cookie 與瀏覽器儲存（localStorage）

  • 本站使用瀏覽器的 localStorage 儲存匿名訪客代碼，以及你的偏好設定（例如播放速度、自動跟隨、是否同意追蹤）。
  • 本站本身不設定廣告或第三方追蹤 cookie。使用 Google 登入時，Google 可能依其隱私權政策設定自己的 cookie。
  • 清除瀏覽資料即可刪除本站存在你瀏覽器中的資料。

12. 你的權利

  • 依台灣《個人資料保護法》，你可以查詢、閱覽或取得副本、補充或更正、要求停止蒐集／處理／利用，以及要求刪除你的個人資料。
  • 歐盟／歐洲經濟區的使用者另享有《一般資料保護規則》（GDPR）的權利，包括存取、更正、刪除、限制處理、資料可攜、反對處理，以及隨時撤回同意（撤回不影響撤回前處理的合法性），並可向所在地的資料保護主管機關申訴。
  • 行使權利請寄信到 rooteric@gmail.com。

13. 測試期說明

  • 本服務目前為測試期，訂閱名額上限為 400 位；額滿時暫停接受新訂閱。

14. 政策變更與生效日期

  • 本政策若有修改，會更新本頁並標示新的生效日期；重大變更會在電子報中通知訂閱者。
  • 生效日期：2026-10-25。
